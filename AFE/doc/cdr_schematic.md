# CDR schematic — `afe_cdr_tr` (`AFE/spice/afe_cdr_tr.sp`)

*Transistor-level design of the CDR upper loop that `AFE/veriloga/afe_cdr.va` models ([cdr.md](cdr.md)): same pins, same behaviour, same loop numbers. Process: 180 nm, 1.8 V core devices. The xh018 models are not in this repo, so it is sized and simulated with the placeholder `AFE/spice/models/generic180.lib` (typical published 0.18 µm values, BSIM3v3; see [AFE/spice/README.md](../spice/README.md)). Status: 2026-11-12, simulated with ngspice 42 at tt (closed loop) and five corners (VCO); not run in Spectre; no layout.*

The netlist is the schematic's source (the logic cells, flip-flops, bias, charge pump and VCO are in `AFE/spice/afe_cells.sp`, shared with the PLL `afe_pll_tr.sp`, [pll_schematic.md](pll_schematic.md)): every device, size and connection below is taken from it. Cell names and device names are the instance names in the netlist. Drawn sheets of the same circuit: `AFE/spice/doc/cdr_{top,pd,dff,cp,vco,bias}.svg`, generated by `AFE/spice/doc/draw_cdr.py` from the instance names and sizes.

## 1. Block diagram

```
                        ┌─────────────── cdr_pd ──────────────┐       ┌──── cdr_cp ────┐
 CDR_DATA ─XB0─XB1─ din ┤ FFA (↑) ── qa ── FFC (↑) ── qc      │ upb,up│ ICP = 50 µA    │
                        │ FFB (↓) ── qb ── FFD (↑) ── qd      ├──────►│ steering pairs ├──► CDR_CH_OUT
                        │ UP = qc ⊕ qd   DN = qa ⊕ qd  (& en) │ dn,dnb│ vrep follower  │      │
                        └────▲──────────────────┬─────────────┘       └────────────────┘      │
                             │ ckpd             │ qa                     C1 0.1 pF ═══╪═══ R8 2 kΩ ── nz ── C2 40 pF
                             │                  └─ XQA─XO0(NAND en)─XO1─XO2 ──► HS_RXD        │
                             │                                                                │ (fine)
         INV1─INV2─INV3 ─────┘                ┌──────── vco_v2i ───────┐                      │
   n5 ──┤          └─INV4─INV5 ──► CLK_RX     │ MC (CDR_V_IN_2) + RC   │◄─────────────────────┘
        │                                     │ MF (CDR_CH_OUT) + RF   │◄── CDR_V_IN_2 (coarse, from the PLL)
        └──── vco_ring (5 starved stages) ◄───┤ MOFF (offset)          │
                    vcp / vcn ◄───────────────┤ MPD → MPM → MND        │
                                              └────────────────────────┘
   cdr_bias (β-multiplier, 10 µA): vbn / vbp → CP sources, vrep OTA, MOFF
   CDR_EN → XE0 / XE1 → en / enb: bias, V-to-I, ring clamps, UP / DN gates, HS_RXD force, filter reset
```

The analog team's labels are kept where they exist: `CDR_R8`, `CDR_C2`, `CDR_C1` (loop filter), `CDR_INV1` / `CDR_INV3` / `CDR_INV5` (clock buffer; INV3 feeds the phase detector clock, as in the block description; INV2 and INV4 are added so that CLK_RX and the PD clock have the same polarity).

## 2. Sub-circuits

### 2.1 Enable and data input

| Instance | Device / cell | Size (W/L in µm) | Function |
|---|---|---|---|
| XE0, XE1 | inv | 0.5/1.2, 1/2.5 | `enb`, `en` from `CDR_EN` |
| XB0, XB1 | inv | 1/2.5, 2/5 | `CDR_DATA` (RX_OUT_P, 1.8 V logic) → `din`: restores edges, drives FFA and FFB |

Logic cells use L = 0.18 µm; `inv wn/wp` gives NMOS / PMOS widths.

### 2.2 Phase detector `cdr_pd` (Alexander)

```
 din ──┬──► D FFA(↑) Q ── qa ──┬─► D FFC(↑) Q ── qc
       │                       │
       └──► D FFB(↓) Q ── qb ──┼─► D FFD(↑) Q ── qd
                               │
   qc ⊕ qd ─ upx ─┐            │      qa ⊕ qd ─ dnx ─┐
                  NAND(en) ─ upb ─ inv ─ up          NAND(en) ─ dnb ─ inv ─ dn
```

On the rising `ckpd` edge k: `qa` = D(k), `qc` = D(k−1), `qd` = edge sample between k−1 and k (FFB on the falling edge, retimed by FFD). UP = `qc` ⊕ `qd` (edge sample equals the new bit: clock late), DN = `qa` ⊕ `qd` (edge sample equals the old bit: clock early). Both are zero without a transition and hold for one bit, as in `afe_cdr.va`.

**Flip-flop `dffp` / `dffn`** (master-slave transmission gate, static, local clock buffer):

```
            ck ─XC0─ ckb ─XC1─ cki
 d ─XT1─ m ─XI2─ mb ─XT3─ s ─XI4─ q
        └─XT2─XI3─┘        └─XT4─XI5─┘   (feedback, weak)
 dffp: XT1 / XT4 on while ck = 0, XT2 / XT3 on while ck = 1 (rising edge)
 dffn: phases swapped (falling edge), same delay from ck
```

| Device | wn / wp (µm) |
|---|---|
| XC0, XC1, XI2 | 0.8 / 2 |
| XT1, XT3 (TG) | 0.5 / 1.2 |
| XI3, XI5, XT2, XT4 (keepers) | 0.3 / 0.5 |
| XI4 (output) | 1.2 / 3 |

The negative-edge flop swaps the latch phases instead of inverting the clock, so the edge sample has no extra inverter delay (that would shift the sampling point by about 0.02 UI).

**XOR `xor2`**: two transmission gates (0.8 / 2), `y = b ? !a : a`; the NAND with `en` behind it restores the level. NAND2 0.8 → 2 / 2.5 µm (series NMOS 2 µm), output inverters 1 / 2.5 µm.

### 2.3 Charge pump `cdr_cp` (current steering, ICP = n · I0 = 50 µA with n = 5; the PLL uses n = 2)

```
            VDD
             │
       XPSRC 5 × 4/1 (vbp)          XO3 4/0.5 ┐┌ XO4 4/0.5
             │ sp                           o1 ││ vrep
     upb ─┤ XPSW 4/0.18     up ─┤ XPDMP     XO1 8/0.5 (out) XO2 8/0.5 (vrep)
             ├────── out ─────┐        vrep     └── ot ── XOT 2/1 (vbn)
     dn  ─┤ XNSW 2/0.18   dnb ─┤ XNDMP     CVR 1 pF on vrep
             │ sn
       XNSRC 5 × 2/1 (vbn)
             │
            VSS
```

The sources conduct all the time; each switch pair steers the current to `out` (CDR_CH_OUT) or to `vrep`, which the OTA follower (XO1–XO4, XOT, 10 µA) holds at V(out). So the source drains do not jump when a switch closes, and there is no charge sharing at the start of a pulse. Long-channel sources (L = 1 µm) for output resistance and matching. The UP / DN current mismatch over the output range has not been characterised yet (section 6); in a bang-bang loop it shifts the sampling point slightly but does not change the lock behaviour.

### 2.4 Loop filter

| Element | Value | Device |
|---|---|---|
| C1 (`CDR_C1`) | 0.1 pF (+ about 30 fF node parasitics) | MIM |
| R8 (`CDR_R8`) | 2 kΩ | high-ohmic poly |
| C2 (`CDR_C2`) | 40 pF | NMOS capacitor 48 × 10 µm × 10 µm (≈ 8.4 fF/µm², node at 0.9 V, well in inversion), ≈ 4800 µm² |

Changed from the Verilog-A model's idealized values (ICP 100 µA, R8 1 kΩ, C2 500 pF) to values that fit on silicon, with the **same proportional step**: ICP · R8 · K_fine · T_bit = 50 µA · 2 kΩ · 300 MHz/V · 2.083 ns = 0.0625 UI (130 ps) per decision. The integral step is 50 µA · 2.083 ns / 40 pF · 300 MHz/V = 0.78 MHz (1630 ppm) per net decision instead of 260 ppm, and the stability ratio T_bit / (R8 · C2) = 0.026 stays small (proportional path dominates). See section 4 for the lock and ±1000 ppm results.

**Reset while CDR_EN = 0:** divider XR0 (PMOS 8 µm, on while en = 0; wider than XR1 so both switches drop the same, which puts `vmid` at 0.900 V) – RR0 20 kΩ – `vmid` – RR1 20 kΩ – XR1 (NMOS 2 µm), and transmission gates XTR0 / XTR1 (2 / 4 µm) from `vmid` to CDR_CH_OUT and to `nz`. Current 45 µA while disabled, none while enabled.

### 2.5 VCO

**V-to-I `vco_v2i`:**

```
                 VDD ─────────────┬──────────────────┐
                                  │                  │
                          XMPD 2×10/0.36 (diode)  XMPM 2×10/0.36
                                  │ vcp ──────────┘  │ vcn
             ┌────────────────────┼──────────┐       XMND 2×4/0.36 (diode)
  CDR_V_IN_2 ┤ XMC 20/0.36   CDR_CH_OUT ┤ XMF 20/0.36   XMOF 16×2/1 (vbn, 160 µA)
             │ RC 5 kΩ               │ RF 3.2 kΩ        │
             └──────────── ng ───────┴──────────────────┘ (XMOF to VSS)
                           │ XSW 40/0.18 (en)
                          VSS
```

`I_ref` = I(XMC) + I(XMF) + I(XMOF); the ring stages mirror it through `vcp` (PMOS starving) and `vcn` (NMOS starving). The source resistors linearize the tuning; their ratio sets K_coarse / K_fine. The offset current (16 × 10 µA from the bias) puts the curve at 400 MHz with the coarse input at 0.5 V. Power-down: XPD1 pulls `vcp` to VDD, XPD2 pulls `vcn` to VSS, XSW opens.

**The PLL VCO must be this same cell** (V-to-I + ring + INV1-sized load) with its fine input (XMF gate) on a 0.9 V reference. Then CDR_V_IN_2 = CDR_CH_OUT_PLL puts the CDR VCO at 480 MHz · (1 + mismatch) without data (assumption D1); the mismatch is risk R3 and needs a Monte Carlo run with the xh018 mismatch models and matched layout (common centroid, the two rings side by side).

**Ring `vco_ring`, stage `vco_stage`:**

```
 VDD ── XPS 10/0.36 (vcp) ── XPI 5/0.18 ──┬── out        × 5 stages, n1 … n5, n5 → stage 1
                                    in ───┤
 VSS ── XNS 4/0.36 (vcn)  ── XNI 2/0.18 ──┘
```

Starving devices on the supply side, L = 0.36 µm. Every node has the same load: the real INV1 on `n5`, dummy inverters XD1–XD4 (1 / 2.5 µm) on `n1`–`n4`. **Clamp while CDR_EN = 0:** XC1, XC3, XC5 (PMOS 0.5 µm) pull `n1`, `n3`, `n5` high, XC2, XC4 (NMOS 0.5 µm) pull `n2`, `n4` low, with the starving devices off: no node floats, no current, and `n5` = 1 → CLK_RX = 0. At enable, stage 1 sees the one inconsistent input (`n5` = 1, `n1` = 1) and the ring starts at once.

**Clock buffer:** INV1 1/2.5 → INV2 2/5 → INV3 4/10 (`ckpd`, 4 flip-flop clock inputs + INV4) → INV4 2/5 → INV5 6/15 (CLK_RX, 100 fF load in the testbench).

### 2.6 Retimed data

XQA (inv) → XO0 NAND2(`qan`, `en`) → XO1 1/2.5 → XO2 3/7.5 → HS_RXD. HS_RXD = `qa` while enabled and 1 (isolated J) while CDR_EN = 0.

### 2.7 Bias `cdr_bias` (constant-gm reference, 10 µA)

```
 VDD ─ XM3 4/1 (diode, vbp) ──────┐   ┌─ XM4 4/1
                                 vbp  vbn
 VSS ─ RB 10 kΩ ─ xs ─ XM2 4×2/1 ─┘   └─ XM1 2/1 (diode)
 start-up: XS1 0.5/8 (PMOS load) + XS2 1/0.5 (vbn) → st → XST 1/0.5 pulls vbp while vbn is low
 power-down: XPD1 (vbp → VDD), XPD2 (vbn → 0), XPD3 (st → 0)
```

I0 = 2 / (µn·Cox·(W/L)₁·RB²) · (1 − 1/√4)²; RB high-ohmic poly. Mirrors: NMOS 2/1 per 10 µA (`vbn`), PMOS 4/1 per 10 µA (`vbp`). Users: CP sources (×5 each), OTA tail (×1), VCO offset (×16).

## 3. Pins

Same order and meaning as `afe_cdr.va` ([cdr.md](cdr.md)): `CDR_DATA CDR_EN CDR_V_IN_2 CLK_RX HS_RXD CDR_CH_OUT VDD18A VSS18A`. CDR_V_IN_2 is a gate only (high impedance). CDR_CH_OUT is the filter node (observe through a high-impedance analog test bus only: every fA of leakage is a frequency offset of the integral path).

## 4. Simulated results (ngspice, generic180 tt, 27 °C, 1.8 V)

`python3 AFE/spice/tb/tb_cdr_tr.py` (ngspice 42, 10 ps maximum step, trapezoidal integration; the stimulus sources drive CDR_DATA / CDR_EN through 500 Ω so that ngspice does not stall at their PWL corners). Stimulus as in `tb_afe_cdr.va`: CDR_EN low for 2 µs (filter reset), 300 ns free-running, then packets of 12-bit SYNC (KJKJ…KK), PRBS7 payload as NRZI line levels, 8-bit EOP and 20–60 idle bits, each starting at a random fraction of a bit. CDR_V_IN_2 = 0.917 V stands in for the PLL (480 MHz on this VCO's coarse curve with the fine input at 0.9 V). Loads: 100 fF on CLK_RX, 50 fF on HS_RXD.

At ss / 125 °C / 1.62 V the coarse curve compresses: 469.8 / 478.4 / 485.3 / 489.3 MHz at 1.1 / 1.2 / 1.3 / 1.4 V, so the PLL needs CDR_V_IN_2 ≈ 1.23 V for 480 MHz and has about 2 % range left. The cause is headroom: at 1.62 V the diode XMPD leaves too little drain voltage for XMC, which goes into triode. The fine gain halves there too (139 MHz/V), which halves the proportional step. See section 6.

### 4.2 Closed loop (tt, 27 °C, 1.8 V)

| Check | Requirement | Result |
|---|---|---|
| Lock time, 12 short packets at 0 ppm (bits from the first transition to the last sampling edge closer than 0.15 UI to a data edge) | ≤ 6 bits (spec 4.2, `HS_ZMIN` 4 / `LOCK_DLY` 2) | mean 1.2, worst 4 bits |
| Sampling margin after lock | ≥ 0.15 UI | min 0.16, mean 0.47 UI (0 ppm); min 0.38 (+1000 ppm), 0.17 (−1000 ppm) |
| HS_RXD sampled by the rising CLK_RX edge | equals the transmitted bit, no slip | 970 / 970 bits (0 ppm), 1598 / 1598 bits each at +1000 and −1000 ppm (1600-bit packets); latency 1 CLK_RX cycle |
| HS_RXD setup / hold at the CLK_RX pin | ≥ 0.4 ns / ≥ 0.1 ns | 1.67 ns / 0.285 ns |
| Free-running CLK_RX after the filter reset (D1) | 480 MHz ± 0.25 % | 480.12 MHz (+245 ppm) |
| Free-running CLK_RX after the packets | 480 MHz ± 0.25 % | +10 ppm (after 0 ppm data), −827 ppm (after −1000 ppm), +1630 ppm (after +1000 ppm) |
| CDR_EN = 0 | CLK_RX low and quiet, HS_RXD = 1, CDR_CH_OUT → VDD/2 | 0 edges, 0.00 V; 1.80 V; 0.900 V |
| Supply current | — | 1.29 mA receiving (average), 47 µA with CDR_EN = 0 (the reset divider) |

Sampling instant: the PD flip-flops sample CDR_DATA 207 ps before the CLK_RX crossing (the data input buffer adds 80 ps, INV4 / INV5 delay CLK_RX by 127 ps). `tb_afe_cdr_tr.scs` passes this as `t_smp` to the Spectre checker.

**Integral-path granularity.** One net decision changes the C2 voltage by ICP · T_bit / C2 = 2.6 mV, i.e. 0.78 MHz (1630 ppm). That is larger than the ±1000 ppm the loop has to track. The loop tracks anyway, because the proportional path (62 500 ppm per decision) dominates: no errors and a min margin of 0.17 / 0.38 UI in the ±1000 ppm packets. But the frequency stored on C2 when a packet ends sits within about one integral step of the data rate, not on it: −827 ppm after a −1000 ppm packet, +1630 ppm after +1000 ppm. The digital elastic buffer doesn't care (it sees the clock only during packets), but a dual-path pump (section 6) would bring the step down to the model's 260 ppm.

Integration method: gear integration (`method=gear`) ran the oscillator about 0.15 % slow against trapezoidal integration and stalled in the +1000 ppm case; the numbers above are all from trapezoidal runs.

DC operating point: with CDR_EN = 0 and no history, `.op` leaves the PD latches at their metastable midpoint and reports 350 µA. In transient the latches hold valid levels and the disabled current is 47 µA.

## 5. Differences from `afe_cdr.va`

| Item | `afe_cdr.va` | `afe_cdr_tr.sp` | Why |
|---|---|---|---|
| ICP, R8, C2 | 100 µA, 1 kΩ, 500 pF | 50 µA, 2 kΩ, 40 pF | 500 pF does not fit on silicon; the proportional step is unchanged (0.0625 UI) |
| Integral step | 260 ppm per decision | 1630 ppm per decision | consequence of the smaller C2 (section 4.2) |
| Coarse curve | linear, clamped to 400–500 MHz | 404–496 MHz over 0.5–1.0 V at tt, unclamped, compresses at low VDD | real V-to-I |
| Sampling instant | at the CLK_RX edge | 207 ps before the CLK_RX crossing | clock buffer INV4 / INV5 and data input buffer |
| HS_RXD after CLK_RX | `t_cq` 0.3 ns | 0.285 ns (hold) | flip-flop + NAND + 2 inverters, minus the INV4 / INV5 lag |
| Below `vdd_min` | CDR off | no UVLO in the block | the power sequencer keeps CDR_EN low until PG18A (spec 3.6) |
| Filter reset | 100 Ω to `vf_mid` | 20 kΩ / 20 kΩ divider + TGs, τ ≈ 0.4 µs | keeps the disabled current at 45 µA |

## 6. Open points

1. **Coarse headroom at low VDD** (section 4.1): at ss / 125 °C / 1.62 V the PLL needs CDR_V_IN_2 ≈ 1.23 V and the curve flattens at 489 MHz. Fix with the xh018 models: widen XMPD / XMPM (lower Vsg) or move part of the current into XMOF, then recheck the coarse range at all corners together with the PLL's charge-pump compliance. The transistor PLL confirms the problem: at this corner it stops at 479.57 MHz (−901 ppm) with CDR_CH_OUT_PLL at 1.365 V, the charge-pump limit, because its fine reference VDD/2 is only 0.81 V there ([pll_schematic.md](pll_schematic.md) 4.2). The fine gain halves at the same corner; check the lock time there.
2. **Dual-path charge pump**: a second, smaller pump (about ICP / 8) straight into C2, with the main pump into R8 only, would bring the integral step to the model's 260 ppm without a larger C2.
3. **PLL VCO = this VCO** (risk R3): done, `afe_pll_tr.sp` uses the same cells with XMF on a VDD/2 reference. Its curve sits +0.4 % above this one at 0.9 V because the two fine references differ by a few mV ([pll_schematic.md](pll_schematic.md) 4.1); derive both from one divider. The random part needs a Monte Carlo run with the xh018 mismatch models; place the two rings side by side.
4. **xh018 models**: replace `generic180.lib`, map `nch` / `pch` in the `nfet` / `pfet` wrappers, use PDK resistors and capacitors, retune RC / RF / XMOF to the curve in section 4.1, and rerun `tb_cdr_tr.py` at all corners (only the VCO has been run at corners so far; lock was simulated at tt only).
5. **Jitter and supply noise**: not simulated. The single-ended ring has no supply rejection beyond the starving devices; a supply step on VDD18A moves the frequency directly. Measure with a noise transient (ngspice `trnoise`) or Spectre pnoise once the models are in.
6. **Charge-pump mismatch**: sweep CDR_CH_OUT 0.6–1.2 V with UP and DN on separately and record I_up / I_dn (and the static phase offset it causes in closed loop).
7. **Spectre run** of `veriloga/tb/tb_afe_cdr_tr.scs`: written, not run (no Spectre here).
8. **Layout**: C2 ≈ 4800 µm² of NMOS capacitor; guard ring around the ring VCO, separate VDD18A for the VCO and the logic of the PD if possible.
