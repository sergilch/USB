# PLL schematic — `afe_pll_tr` (`AFE/spice/afe_pll_tr.sp`)

*Transistor-level design of the PLL (lower loop of the CDR block) that `AFE/veriloga/afe_pll.va` models ([pll.md](pll.md)): same pins, same behaviour, same loop numbers. Process: 180 nm, 1.8 V core devices, sized and simulated with the placeholder `AFE/spice/models/generic180.lib` (see [AFE/spice/README.md](../spice/README.md)). Status: 2026-11-12, simulated with ngspice 42 at tt (all cases, passing) and two corners (24 MHz lock: passes at ff / −40 °C / 1.98 V, **fails at ss / 125 °C / 1.62 V**, open point 1); not run in Spectre; no layout.*

The netlist is the source of the schematic; device names below are its instance names. The charge pump, bias, logic cells and **the whole VCO are shared with the CDR** (`AFE/spice/afe_cells.sp`), as the PLL-assisted CDR requires: the CDR's VCO then free-runs at the PLL's frequency without data. Their schematics are in [cdr_schematic.md](cdr_schematic.md) sections 2.3, 2.5 and 2.7. Drawn sheets: `AFE/spice/doc/pll_{top,pfd,div,cp,filter}.svg` and `cdr_vco.svg`, generated by `AFE/spice/doc/draw_pll.py` / `draw_cdr.py`.

## 1. Block diagram

```
 CDR_FREF ─XF0─┬─XF1──────────────────────────────────────────────► REF_DIG (always on)
               └─XF2─ ref_i ─► pll_pfd ─ up/upb, dn/dnb ─► cdr_cp (n = 2, 20 µA) ─┬─► CDR_CH_OUT_PLL
                                 ▲ fb                                              │   (→ CDR_V_IN_2 of the CDR)
                                 │                       C4 1.53 pF ══╪══ R2 34.5 kΩ ── nz ── C3 15.1 pF
                                 │                                    │ coarse
          pll_div (÷5 → ÷4/÷5) ◄─┼─ ckd ◄─ INV3 ◄─ INV2 ◄─ INV1 ◄─ n5 ◄─ vco_ring ◄─ vco_v2i ◄─ vref (VDD/2, fine)
          sel5 = NOR(REFSEL1, REFSEL0)        └─ INV4 ─ INV5 ──────────────────────────────────► CLK_BIT_A
   cdr_bias (β-multiplier, 10 µA)      PLL_EN → XE0 / XE1 → en / enb
```

## 2. Sub-circuits

### 2.1 Reference and enable

| Instance | Size (W n / p, µm) | Function |
|---|---|---|
| XF0 | 1 / 2.5 | CDR_FREF input buffer |
| XF1 | 2 / 5 | REF_DIG driver. Not gated by PLL_EN: the lock detector's heartbeat check needs the reference while the PLL is off (Q7) |
| XF2 | 1 / 2.5 | `ref_i` into the PFD |
| XE0, XE1 | 0.5 / 1.2, 1 / 2.5 | `enb`, `en` |
| XS0 | NOR2 0.5 / 2.4 | `sel5` = 1 for REFSEL = 00 (÷25) |

### 2.2 Phase-frequency detector `pll_pfd`

Two dynamic TSPC flip-flops with D = 1 (`pfd_ff`), one clocked by `ref_i` (UP), one by `fb` (DN):

```
 VDD ─ XP2 2/0.18 (rst) ─ XP1 2/0.18 (ck) ─┬─ n1 ─┬──────────────── XP3 2/0.18 (n1) ─ VDD
                                           │      │                    │
                              XN2 1/0.18 (rst)    │                    ├── qb (UP / DN active low)
                                           │      │                    │
                                          VSS     │   XN4 2/0.18 (ck) ─┘
                                                  └── XN5 2/0.18 (n1) ─ VSS
```

A rising `ck` with n1 precharged high pulls `qb` low. `rst` pulls n1 low and `qb` high. The precharge path has XP2 in series, so a reset that arrives while `ck` is still low does not fight XP1. Reset: XR0 NAND(up, dn) → XR1, XR2 inverters → XR3 NAND(·, en), i.e. `rst` = (up · dn) delayed, or PLL_EN = 0. The simulated UP / DN pulse in lock is 365 ps wide, which covers the charge pump's switching time, so there is no dead zone. Outputs: `up` = XIU(qu), `upb` = XIUB(up), likewise `dn` / `dnb` (inverters 1 / 2.5 µm).

### 2.3 Charge pump

The CDR's current-steering pump `cdr_cp` with n = 2: sources 2 × 4/1 (PMOS) and 2 × 2/1 (NMOS) from the 10 µA bias, so ICP = 20 µA, the model's value. Switch pairs and the `vrep` OTA follower as in [cdr_schematic.md](cdr_schematic.md) 2.3.

### 2.4 Loop filter, discharge, fine reference

| Element | Value | Device |
|---|---|---|
| C4 (`CDR_C4`) | 1.53 pF | MIM |
| R2 (`CDR_R2`) | 34.5 kΩ | high-ohmic poly |
| C3 (`CDR_C3`) | 15.1 pF | NMOS capacitor 18 × 10 µm × 10 µm (≈ 1800 µm²) |
| XD0, XD1 | NMOS 2/0.18, gate `enb` | discharge CDR_CH_OUT_PLL and `nz` to VSS while PLL_EN = 0 |
| XQ0, RQ0, RQ1, XQ1, XCQ | PMOS 8/0.18 (`enb`), 2 × 100 kΩ, NMOS 2/0.18 (`en`), NMOS cap 10×10 (0.84 pF) | `vref` = VDD/2 for the VCO's fine input, 9 µA, off while PLL_EN = 0 |

These are the model's values; they fit on silicon as they are. With this VCO (K = 182 MHz/V instead of 200) the loop constant is 10 % lower than in [pll.md](pll.md), so the crossover is about 0.95 MHz and the phase margin stays near 56°. While the PLL is off, the filter is discharged, so the VCO restarts from the bottom of its range (392 MHz at 0 V), as `afe_pll.va` does.

### 2.5 VCO

The CDR's VCO without changes: `vco_v2i` (coarse input XMC = CDR_CH_OUT_PLL, fine input XMF = `vref`), `vco_ring` (5 current-starved stages, clamped while PLL_EN = 0 so CLK_BIT_A stops low), and INV1 (1 / 2.5 µm) on `n5`, so the ring sees the same load as in the CDR. See [cdr_schematic.md](cdr_schematic.md) 2.5.

### 2.6 Clock buffer

INV1 1/2.5 → INV2 2/5 → INV3 4/10 (`ckd`: divider clock) → INV4 4/10 → INV5 12/30 → CLK_BIT_A (200 fF load in the testbench, the root of the digital clock tree).

### 2.7 Feedback divider `pll_div`

```
 ÷5 at 480 MHz (ckd):      A ← NOR(B, C),  B ← A,  C ← B      states 000 → 100 → 110 → 011 → 001
 ÷4 / ÷5 at 96 MHz (qa):   D ← AOI21(E, F, sel5) = !(E | F·sel5),  E ← D,  F ← E
                           sel5 = 0: D / E form a Johnson pair → ÷4;  sel5 = 1: ÷5
 fb = D:  N = 20 (REFSEL 01, 10, 11), N = 25 (REFSEL 00)
```

Six `dffp` flip-flops (the CDR's transmission-gate flip-flop), NOR2 and AOI21 (NMOS 0.5 / 1 µm, PMOS 2.4 µm). Only one gate sits between flip-flops at 480 MHz. Both state machines are self-starting: every unused state enters the cycle within two clocks. The divider is not reset by PLL_EN; it keeps its state while the VCO is stopped.

## 3. Pins

Same order and meaning as `afe_pll.va`: `CDR_FREF PLL_EN REFSEL1 REFSEL0 CLK_BIT_A REF_DIG CDR_CH_OUT_PLL VDD18A VSS18A`. CDR_CH_OUT_PLL connects to CDR_V_IN_2 of the CDR (a gate, no load). `prog_div` = 1 behaviour (REFSEL decoded); there is no fixed-÷20 option.

## 4. Simulated results (ngspice)

`python3 AFE/spice/tb/tb_pll_tr.py` (ngspice 42, 20 ps maximum step, trapezoidal integration). Reference: ideal pulse source (0.2 ns edges) through 500 Ω. PLL_EN rises at 0.2 µs with the filter discharged; loads 200 fF on CLK_BIT_A, 50 fF on REF_DIG.

### 4.1 VCO (tt, 27 °C, 1.8 V; CDR_CH_OUT_PLL forced, fine input on `vref`)

| CDR_CH_OUT_PLL | 0 V | 0.5 V | 0.7 V | 0.9 V | 1.0 V | 1.2 V |
|---|---|---|---|---|---|---|
| CLK_BIT_A | 392.3 MHz | 405.2 | 438.9 | 478.4 | 496.4 | 536.2 |
| `afe_pll.va` | 400 (clamped) | 400 | 440 | 480 | 500 | 500 (clamped) |

K_vco 182 MHz/V (0.5–1.0 V; model 200). The same cell in the CDR gives 476.6 MHz at 0.9 V with its fine input at 0.900 V; here `vref` sits a few mV higher, which is +0.4 % (3800 ppm). The CDR's fine loop absorbs this at every packet, but it is the first number of the R3 mismatch budget (section 6). Over corners the VCO behaves as in [cdr_schematic.md](cdr_schematic.md) 4.1.

**ss / 125 °C / 1.62 V fails.** The loop runs out of range: CDR_CH_OUT_PLL climbs to 1.365 V, where the charge pump's PMOS source has no headroom left (DN pulses grow to 3.1 ns while UP stays at 0.6 ns), and CLK_BIT_A stops at 479.57 MHz, 901 ppm low. This is the coarse-headroom problem of [cdr_schematic.md](cdr_schematic.md) 6.1, made worse by the fine reference: `vref` = VDD/2 is 0.81 V at 1.62 V instead of 0.9 V, which costs about 12 MHz (K_fine 139 MHz/V there) and so 0.15 V more on the coarse input than the 1.23 V found with the fine input at 0.9 V. The fix belongs in the shared VCO (section 6.1); the PLL itself (PFD, divider, disable) works at both corners. At ff / −40 °C / 1.98 V everything passes.

**26 MHz.** `afe_pll.va` stops at its 500 MHz limit; a real VCO with range for PVT reaches 520 MHz and locks there. The digital is safe either way: `usb_pll_lock_det` expects 4726 counts for 26 MHz, sees 5120, and never reports lock; REFSEL 10 also sets `refsel_err`. `tb_afe_pll_tr.scs` checks 515–525 MHz instead of 499–501 (checker parameters `f26_lo` / `f26_hi`).

## 5. Differences from `afe_pll.va`

| Item | `afe_pll.va` | `afe_pll_tr.sp` | Why |
|---|---|---|---|
| VCO range | clamped to 400–500 MHz | 392 MHz at 0 V, no upper clamp (536 MHz at 1.2 V, tt) | real VCO; the range must cover PVT. 26 MHz with ÷20 locks at 520 MHz (harmless, see 4.2) |
| K_vco | 200 MHz/V | 182 MHz/V | shared CDR VCO |
| PFD | ideal reset, no pulse | TSPC flip-flops, 365 ps reset pulse | no dead zone; costs a small reference spur (0.26 ps rms period spread) |
| Divider | ideal, no delay | ripple of two synchronous stages; fb delay is inside the loop and does not matter | |
| `prog_div` = 0 (fixed ÷20) | parameter | not built | REFSEL decode only |
| REF_DIG delay | 0.2 ns | 159 ps | two inverters |
| Below `vdd_min` | PLL off | no UVLO in the block | the power sequencer holds PLL_EN low until PG18A (spec 3.6) |
| `f_err`, `jit_rms` | fault / jitter injection | — | model-only parameters |

## 6. Open points

1. **Lock fails at ss / 125 °C / 1.62 V** (section 4.2): the shared VCO needs about 1.38 V on the coarse input there and the charge pump's PMOS side stops at about 1.36 V. Fixes, to be done in the shared cell with the xh018 models and checked in both testbenches: more VCO range at low VDD (wider XMPD / XMPM, more XMOF offset current, see [cdr_schematic.md](cdr_schematic.md) 6.1); a fine reference that does not track VDD (both the PLL's `vref` and the CDR's reset divider are VDD/2 today, so changing them together keeps the two VCOs matched); or a VCO supply from a regulator. Until then the PLL meets spec 4.3 only from tt to ff.
2. **VCO mismatch between PLL and CDR (risk R3)**: the systematic part is +0.4 % from the fine references (PLL `vref` vs the CDR's reset divider). Derive both from one divider, or trim them, and add the random part from a Monte Carlo run with the xh018 mismatch models. Lay the two rings out side by side.
3. **Noise**: jitter, reference spurs and supply sensitivity are not simulated (no noise sources). The digital needs only the per-period figure; the HS TX eye needs the accumulated jitter over the 480 MHz bit clock.
4. **Lock detector in the loop**: `tb_pll_tr.py` measures frequency; the window count of `usb_pll_lock_det` (5120 ± 5) over 10.7 µs windows is checked only in the Spectre testbench `veriloga/tb/tb_afe_pll_tr.scs` (written, not run). A co-simulation with `usb_pll_lock_det` + `usb_clk_gen` behind this netlist is the next step (the AMS testbench `tb_ams_pwr` with the transistor PLL in place of `afe_pll.va`).
5. **xh018 models**: as for the CDR (replace `generic180.lib`, PDK resistors and capacitors, retune the shared VCO, rerun both testbenches).
