# Receiver schematic — `afe_receiver_tr` (`AFE/spice/afe_receiver_tr.sp`)

*Transistor-level design of the HS receive front end that `AFE/veriloga/afe_receiver.va` models ([receiver.md](receiver.md)): HS receiver, squelch detector and HS disconnect detector, same pins, same off states. Process: 180 nm, 1.8 V core devices plus 3.3 V thick-oxide devices for the input stages, sized and simulated with the placeholder `AFE/spice/models/generic180.lib` (see [AFE/spice/README.md](../spice/README.md)). Status: 2026-11-13, simulated with ngspice 42 at tt, ss / 125 °C / 3.0 / 1.62 V and ff / −40 °C / 3.6 / 1.98 V, all passing (section 4); not run in Spectre; no layout; no Monte Carlo.*

The same schematic as a page with the drawn sheets and result tables: [receiver_schematic.html](receiver_schematic.html) (open it in a browser; a snapshot of 2026-11-13, not regenerated when the netlist changes).

The netlist is the source of the schematic; device names below are its instance names (sizes W/L in µm; "33" = thick-oxide `pch33` / `nch33`, L ≥ 0.35 µm). Drawn sheets: `AFE/spice/doc/rx_{top,hs,cmp,dda,logic,bias}.svg`, generated by `AFE/spice/doc/draw_receiver.py`. 249 MOSFETs (212 core, 37 thick oxide).

## 1. Block diagram

```
            RX_VDD (3.3 V, pch33 input stages)          RX_VDDO (1.8 V, core devices)
 RX_IN_P ─┬─ XA1/XA2 pair, 200 µA, 3 kΩ ── xa/ya ──► rx_cmp XHS (hyst.) ─ XH0..XH5 ─► RX_OUT_P, RX_OUT_N
 RX_IN_N ─┤
          ├─ rx_dda XSP / XSN (|vd| > I0·RSQ) ─────► rx_cmp ×2 ─ OR ─► bridge 3 ns ─► on 6 ns / off 10 ns
          │                                                             ─► SR latch ─ & on ─► SQUELCH_A
          └─ rx_dda XDP / XDN (|vd| > I0·RDISC) ───► rx_cmp ×2 ─ OR ─► 4 ns timer ─ & on ─► DISC_A
   references: I0 into the poly string RR0..RR4 (rsl/rsh, rdl/rdh)
 RX_VREF ─► rx_bias: OTA + XM0 + RB 60 kΩ: I0 = V(RX_VREF) / RB = 20 µA ─► vbp18, vbp33
 RX_EN ──► XE0/XE1 (en18) ─ level shifter XL0..XL3 (en33)
 on = en18 · pok (UVLO: RX_VDD > 2.95 V) · rdy (about 170 ns after RX_EN)
```

Two supply domains, as in the model. **RX_VDD** carries only the input stages: thick-oxide PMOS pairs (the HS line sits at 0 … 0.4 V, common mode −50 … 500 mV, so PMOS inputs) into poly resistor loads to RX_GND, which keep every node that crosses into the 1.8 V domain below 0.6 V. **RX_VDDO** carries the bias, the comparators, timers, logic and the output drivers: the outputs swing 0 … RX_VDDO. This is the proposed 1.8 V output stage (Q8); RX_VDDO = RX_VDD (3.3 V outputs) is not possible with this netlist, which uses core devices there.

**One current sets every threshold.** I0 = V(RX_VREF) / RB. The squelch and disconnect references are I0 times resistors of the same poly as RB, and the UVLO compares RX_VDD through a divider with I0 × RUV. So the thresholds are ratios of RX_VREF and resistor ratios, not of absolute resistor values or of transistor parameters.

## 2. Sub-circuits

### 2.1 Bias `rx_bias` (sheet `rx_bias.svg`)

| Instance | Size | Function |
|---|---|---|
| XT0, RT, XT1 | 1/0.18 PMOS switch, 40 kΩ, NMOS 2/1 | crude bias for the OTA tail (about 30 µA), off with RX_EN. The OTA does not depend on I0, so the loop needs no start-up circuit |
| XO0..XO4 | tail 2/1; NMOS pair 4/0.5; PMOS mirror 4/0.5 | 5-transistor OTA, input RX_VREF (1.2 V) against `fb` |
| XM0, RB | PMOS 8/1; 60 kΩ high-ohmic poly | pass device: V(fb) = V(RX_VREF), I0 = 20 µA. The OTA output is `vbp18`, the gate of every 1.8 V current source (8/1 = I0) |
| CC | 0.3 pF MIM | OTA compensation (the mirror gates on `vbp18` add about 1 pF) |
| XM1, XN33D, XN33M, XP33D | PMOS 4 × 8/1; nch33 4 × 4/2; pch33 4 × 16/2 | `vbp33`, the gate of the 3.3 V current sources (pch33 16/2 = I0). The chain runs at 4 · I0 so the large pch33 gate area on `vbp33` charges in about 70 ns |
| XPD0, XPD1, XPD2 | 4/0.18, 2/0.18, pch33 4/0.35 | RX_EN = 0: `vbp18` → RX_VDDO, `n33` → 0, `vbp33` → RX_VDD |

The 3.3 V sources are long (L = 2 µm) because their drains sit at very different voltages from the diode XP33D (up to 2 V apart); with L = 1 µm the references came out 5 % high, with 2 µm 2.5 %. The remaining systematic error is in the thresholds of section 4.1.

### 2.2 HS receiver (sheet `rx_hs.svg`)

| Instance | Size | Function |
|---|---|---|
| XA0 | pch33 10 × 16/2 | tail 200 µA from `vbp33` |
| XA1, XA2 | pch33 24/0.35, n-well tied to the common source `sa` | input pair, gates RX_IN_P / RX_IN_N |
| RA1, RA2 | 3 kΩ poly | loads: `xa`, `ya` at 0.3 V common mode, 0 … 0.66 V; gain about 2.5, pole above 1 GHz |
| XHS | `rx_cmp` mt 5 (100 µA), wi 6, wd 2, wx 2.55, wo 4 | comparator with hysteresis: g1 = `xa`, g2 = `ya` |
| XH0, XH1 | inverters 1/2.5 | `hsb`, `hs` |
| XH2, XH4 | NAND2 2/2.5, inverter 2/5 | RX_OUT_P = `hs` · `on` |
| XH3, XH5 | NOR2 1/5, inverter 2/5 | RX_OUT_N = !(`hs` · `on`) = `hsb` + `onb` (same gate depth as RX_OUT_P) |

DP > DM steers the tail away from XA1, so `xa` < `ya` and the comparator output goes high. The hysteresis is set by wx / wd of XHS (2.55 / 2 gives 18 mV at the input; 2.4 / 2 gave 12 mV, 4 / 3 gave 29 mV) and is the place for the `RX_HYST` trim (spec 6): switch extra cross-coupled width in or out.

### 2.3 Comparator `rx_cmp` (sheet `rx_cmp.svg`)

Allstot / Baker comparator with hysteresis, RX_VDDO domain: PMOS pair XC1 / XC2 (wi/0.25) with tail XC0 (mt · I0); diode loads XC3 / XC4 (wd/0.25) and cross-coupled XC5 / XC6 (wx/0.25): wx > wd gives positive feedback and hysteresis, wx = wd none. The output stage XC7 / XC8 (wo/0.25) mirrors the two branch currents; XC9 / XC10 (PMOS 2.5 · wo) turn the d1 copy around, so `out` is pulled up by I(d1) and down by I(d2): `out` = 1 when V(g2) > V(g1). The inputs run at 0 … 0.6 V, which suits a PMOS pair on 1.8 V. XC11 pulls `out` low and XC12 / XC13 pull d1 / d2 low when `enb` = 1: without XC12 / XC13 the charge left on d1 / d2 kept the output mirror conducting after RX_EN fell (6 µA decaying over microseconds).

| Instance | mt | wi | wd / wx | Use |
|---|---|---|---|---|
| XHS | 5 | 6 | 2 / 2.55 | HS receiver, 18 mV hysteresis |
| XCSP, XCSN | 4 | 3 | 1 / 1 | squelch: fast, no hysteresis (the timers filter) |
| XCDP, XCDN | 4 | 3 | 1 / 1 | disconnect |
| XCU | 1 | 6 | 1 / 1.05 | UVLO, small hysteresis (about 60 mV on RX_VDD) |

### 2.4 Squelch and disconnect preamps `rx_dda` (sheet `rx_dda.svg`)

A differential-difference amplifier: pair A compares in1 with in2, pair B compares the reference pair `rl` / `rh`, each with its own pch33 tail (mt · I0) and its n-well on its own source. The drains add: x = in1-side + `rl`-side, y = in2-side + `rh`-side, into two poly loads. y > x exactly when in1 − in2 > rh − rl. One preamp per polarity: XSP / XDP have in1 = RX_IN_P, XSN / XDN have in1 = RX_IN_N; their comparators are ORed.

| Instance | Tails | Pairs | Loads | Overdrive | Reference |
|---|---|---|---|---|---|
| XSP, XSN | 2 × 100 µA | pch33 16/0.5 | 3 kΩ | 0.22 V | `rsl` 0.1425 V, `rsh` 0.2475 V: 105 mV |
| XDP, XDN | 2 × 40 µA | pch33 1/0.5 | 7.5 kΩ | 0.56 V | `rdl` 0.1125 V, `rdh` 0.6725 V: 560 mV |

**Why these sizes** (found in simulation, kept here because the first versions failed):

- *Linear past the threshold.* Pair B sits at the full threshold difference. In weak inversion (the first squelch preamp had 16/1 pairs at 10 µA) the pair saturates at about 100 mV, so at 125 mV both pairs are on the flat part of their tanh and the gain at the threshold is low. Strong inversion with √2 · Vov above the threshold (squelch 0.31 V > 0.105 V, disconnect 0.79 V > 0.56 V) fixes it.
- *Fast recovery.* At 480 Mbit/s each preamp sees the opposite polarity every other bit and swings −0.3 V the wrong way. With 7.5–15 kΩ loads (τ 0.3–0.65 ns) the squelch preamp had not recovered before the bit ended, and 160 mV alternating data never released the squelch. 3 kΩ with 100 µA tails gives τ ≈ 0.1 ns.
- *Common mode.* A pair with an ideal tail transfers only the differential voltage; with the n-wells on the sources there is no body effect either. So pair B can sit at a fixed common mode (0.195 V squelch, 0.39 V disconnect) while the line moves: the static threshold moves by 2.6 mV over −50 … 500 mV (section 4.1).

**References:** XR0 (pch33 16/2, I0) into RR0 21.25 kΩ, RR1 21.25 kΩ (`rdh`), RR2 5.25 kΩ (`rsh`), RR3 1.5 kΩ (`rsl`), RR4 5.625 kΩ (`rdl`) to RX_GND; CR0..CR3 0.5 pF MIM decoupling on the taps (kick-back from the pairs). RSQ = RR2 (105 mV), RDISC = RR1 + RR2 + RR3 (560 mV). The preamps and comparators add about +4 mV and +3 %, so the static thresholds measure about 110 mV and 578 mV. The squelch reference is deliberately below the model's 125 mV: on alternating data the squelch releases about 30 mV above its static threshold (the preamp is still recovering from the previous bit), and 105 mV puts both the static (110 mV) and the dynamic (140 mV) threshold inside the USB window 100 … 150 mV. These resistors are where the `SQ_VTH` / `DISC_VTH` trims (spec 6) go.

### 2.5 Squelch filter and disconnect timer (sheet `rx_logic.svg`)

**Ramp timer `rx_tmr`:** while `in` = 1, XT0 (PMOS wi/1 from `vbp18`, I0 · wi / 8) charges CT through the switch XT1; `in` = 0 discharges it at once through XT2. Two inverters threshold the ramp at about RX_VDDO / 2: t ≈ CT · RX_VDDO / 2 / I. XT3 holds the ramp at 0 V while the receiver is off (`enb18`), so no inverter input floats (that floating node cost 100 µA in the first version).

| Instance | Input | CT | Time | Model (`afe_squelch`) |
|---|---|---|---|---|
| XTBR (bridge) | `actb` = no comparator active | 60 fF | 3 ns: `env` stays high across dips shorter than this | `t_bridge` 1 ns |
| XTON (on) | `env` | 125 fF | 6 ns of `env` sets `act_f` | `t_sq_on` 4 ns |
| XTOF (off) | `bt` = !`env` | 190 fF | 10 ns without `env` resets `act_f` (13 ns after the last activity) | `t_sq_off` 12 ns in total |
| XTD (disconnect) | `dsc` | 60 fF | 4 ns of `dsc` sets `dsf`; it falls with `dsc` | `t_disc` 4 ns |
| XTRDY (ready) | `en18` | 300 fF, wi 0.8 (I0 / 10) | `on` about 170 ns after RX_EN | — |

The SR latch XS3 (NOR3: `sof`, `onb`, `actf_b`) / XS4 (NOR2: `son`, `actf`) holds `act_f`; `!on` also resets it, so a squelch state picked up while the bias settles never survives. SQUELCH_A = !(`act_f` · `on`) (XS5 NAND, XS6, XS7). DISC_A = `dsf` · `on` (XD2, XD3).

*Why a 3 ns bridge:* at 160 mV the comparators are active for only about 0.5 ns per 2.08 ns bit (the preamp spends the rest recovering), leaving gaps of 1.6–1.8 ns; a 2 ns bridge chattered at tt. The timers trip at RX_VDDO / 2, so they get shorter with the supply (2.5 ns becomes 2.25 ns at 1.62 V); 3 ns leaves margin at every corner. The on timer grew with it, so the shortest activity that releases the squelch is still on − bridge = 3 ns, as in the model (a 2 ns burst is ignored).

*Why the OR gate XS0 is skewed* (NMOS 2 µm, PMOS 1 µm, switching point about 0.5 V instead of RX_VDDO / 2): at ss / 125 °C / 1.62 V the squelch comparators still fire on every bit of 150 mV alternating data, but only as 0.5 ns runt pulses that reach 1.0–1.2 V. A symmetric NOR ignored most of them, and the squelch released only from 155 mV (a longer bridge or a faster preamp did not help). With the skewed gate it releases from 145 mV at ss. The input load is the same as before.

### 2.6 Enable, ready and UVLO (sheet `rx_bias.svg`)

- **Enable:** XE0 / XE1 (RX_VDDO inverters) make `enb18` / `en18`; the level shifter XL0 / XL1 (nch33 2/0.35, driven from 1.8 V) and XL2 / XL3 (cross-coupled pch33 1/0.5) make `en33` and `lsb` (= !`en33`) in the RX_VDD domain.
- **UVLO:** XU0 (pch33, gate `lsb`) switches the divider RU1 474 kΩ / RU2 100 kΩ at the top, so `vdiv` is 0 V while off and never above 0.6 V (it drives a core gate; with the switch at the bottom it floated to 3.3 V). XCU compares `vdiv` with `vuv` = I0 · RUV (XU1 8/1, RUV 25 kΩ, 0.5 V): `pok` = 1 above about 2.95 V. 5.7 µA in the divider while on.
- **Ready:** XTRDY releases `rdy` (and with it `on`) about 170 ns after RX_EN (171–185 ns over the corners), when the bias (45 ns) and the 3.3 V current sources (about 80 ns) have settled. Without it the comparators released SQUELCH_A and DISC_A for a few ns during start-up.
- `on` = `en18` · `pok` · `rdy` (XG0 NAND3, XG1).

## 3. Pins

Same order and meaning as `afe_receiver` in `afe_receiver.va`: `RX_IN_P RX_IN_N RX_EN RX_VREF RX_OUT_P RX_OUT_N SQUELCH_A DISC_A RX_VDD RX_GND RX_VDDO`. RX_EN is a 1.8 V input. RX_VREF drives only the OTA gate (no DC load). RX_VDDO must be 1.8 V. Off (RX_EN = 0, or RX_VDD below about 2.92 V): RX_OUT_P = 0, RX_OUT_N = 1, SQUELCH_A = 1, DISC_A = 0, the isolated values of spec 3.2 / 3.5. RX_EN = 0 also switches off all bias currents.

## 4. Simulated results (ngspice)

`python3 AFE/spice/tb/tb_receiver_tr.py` (ngspice 42, trapezoidal integration, 20 ps maximum step in `seq` / `sqamp`). The line is a realistic HS line: a current-steering driver into 45 Ω at each end makes DP + DM = amplitude, so the common mode is half the amplitude and an idle line sits at 0 V (the Verilog-A testbench instead keeps 200 mV common mode). HS edges 625 ps (0–100 %), as in `tb_afe_receiver`. Stimulus through 500 Ω; 20 fF on every output. The `dc*` cases hold a fixed common mode.

## 6. Open points

1. **Monte Carlo.** Random offsets of the squelch and disconnect preamps (gain about 1 at the threshold) and comparators go straight into the thresholds, and of the HS pair into the hysteresis centre. With the xh018 mismatch models: check the squelch window (static ≥ 100 mV, dynamic ≤ 150 mV) at 3σ; the margin is 8–10 mV at tt but only 4.5 mV (static, 104.5 mV at 500 mV CM) and 5 mV (dynamic, releases from 145 mV) at ss / 125 °C, so this is the first thing to check; the squelch trim is probably needed. The trims `SQ_VTH`, `DISC_VTH`, `RX_HYST` (spec 6) map onto RR1..RR3 and the XHS cross-coupled width.
2. **HS RX delay** is 0.9 ns, three times the model's. The digital does not depend on the absolute value (the CDR retimes), but the A3 squelch / data alignment in spec 4.2 was derived with 0.3 ns; rerun that sweep with `t_dly` 0.9–1.1 ns, or speed up the comparator (a second linear stage in place of the mirror output stage).
3. **Squelch at the USB limit with real data.** The dynamic threshold is measured on alternating data with linear 625 ps edges; check it with the USB receiver eye (template 4) and with ISI from a cable model.
4. **Power:** 4.7 mW while on at tt (4.1–5.3 mW over the corners), 2.9 mW of it on RX_VDD, 1.8 mW in the 3.3 V preamps. The squelch preamps (400 µA) are sized for 0.1 ns recovery; a shared pair A for both polarities or a lower-voltage input stage could halve it.
5. **Turn-on time** (about 170 ns) needs a line in the interface spec (RX_EN to valid outputs) and a check that `usb_afe_rx_if` never expects squelch earlier.
6. **Noise and input protection:** no noise sources (the model's `v_noise`), no ESD devices, and the pch33 gates see the FS / LS line (up to 3.6 V) while the receiver is off: within the thick-oxide rating, to be confirmed with the xh018 rules.
7. **xh018 models:** replace `generic180.lib` (including the placeholder `nch33` / `pch33` cards), use the PDK resistors and capacitors, retune the timer capacitors and the references, rerun `tb_receiver_tr.py` at all corners.
